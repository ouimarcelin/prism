# 0033 – DMX sur le réseau : Art-Net et sACN

- Date : 2026-10-17
- Statut : Acceptée

## Contexte

La phase 5 demande d'envoyer des couleurs à des luminaires DMX (pixel mapping) et de recevoir le DMX d'une console. Les deux protocoles réseau courants sont Art-Net (spécification publique d'Artistic Licence) et sACN (norme ANSI E1.31, publique). Le cahier des charges cite les crates `artnet_protocol` et `sacn`.

## Options

1. **Les crates citées** : plus de code tiers à suivre (licences, dépendances) pour quelques dizaines d'octets d'en-tête.
2. **Nos propres paquets** : seul le paquet de données DMX de chaque protocole est utile ici ; il tient en une centaine de lignes, testées octet par octet.

## Décision

Option 2, crate `prism-dmx` :

- Art-Net : paquet ArtDmx (identifiant, code 0x5000, version 14, séquence, univers sur 15 bits, 512 canaux), port 6454, envoi à une adresse ou en diffusion ;
- sACN : paquet de données (couches racine, trame et DMP), port 5568, envoi au groupe multicast de l'univers (239.255.x.y) ou à une adresse ; priorité 100 ; identifiant de source tiré au lancement ;
- un `DmxSender` par sortie ; un envoi qui ne passe pas tout de suite est abandonné (l'image suivante renvoie l'univers) ;
- les paquets reçus se lisent avec `artnet::parse_dmx` et `sacn::parse_data`.

## Conséquences

- Pas de découverte des appareils (ArtPoll) ni de synchronisation sACN : à ajouter si un appareil l'exige.
- **Ajout du 2026-10-17 (ticket 57) : pixel mapping.** `Lighting` dans la composition : luminaires en lignes de pixels posées sur la composition (début, fin, nombre de pixels), ordre des couleurs (RVB, GRB, RVB + blanc, gradateur), univers et canal de départ, luminosité ; un pixel dont les canaux ne tiennent plus dans l'univers passe au suivant, canal 1 (170 pixels RVB par univers). Le moteur lit les couleurs de l'image programme aux points des pixels sur le GPU (petite image relue sans attendre, comme pour NDI), les range en univers et les envoie à la cadence réglée (40 par seconde par défaut). Adresse « IP » ou « IP:port », vide pour diffuser (Art-Net) ou le multicast (sACN). Réglage dans l'onglet « Lumière (DMX) » de la fenêtre Sortie avancée.
- **Ajout du 2026-10-17 (ticket 58) : réception.** Menu Contrôle > « DMX (console lumière) » : Prism écoute Art-Net (port 6454, tous les univers) ou sACN (port 5568, univers 1 à 16 rejoints en multicast). Chaque canal qui change devient un message de contrôle (`ControlSource::Dmx`, valeur de 0 à 1, appuyé à partir de 128) : il s'apprend comme un fader MIDI et pilote tout ce que pilote le MIDI. Le premier paquet d'un univers fixe seulement où en sont ses canaux. Le port peut être pris par une autre application : l'erreur s'affiche dans le menu.
